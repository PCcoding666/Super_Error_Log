# CONSTRAINTS — 授权与边界

## 已授权

- 项目根目录内删除/替换全部旧源代码与配置，从零重建
- 安装项目级依赖
- 创建/修改/重命名/删除项目根目录内文件
- 启动本地 dev server、跑测试、浏览器自动化、生成本地测试数据与 PDF
- 普通编译/lint/类型/测试/UI 失败自行分析修复，不询问用户

## 必须遵守

- 不得读写项目根目录之外的用户文件
- 不得打印/复制/提交任何 secret、token、PAT、cookie 或个人数据
- 不得远程 push、公开发布、生产部署、购买服务、创建云资源
- 不得 git commit / tag / rebase / reset --hard / force push；进度存 `.ai/` checkpoint
- 不得删除 `.git`
- 不得把真实未成年人样本加入仓库；测试只用自建匿名合成 fixture
- 疑似用户原始数据/私密图片/secret：不删除、不读内容、不复用；记录路径与风险并排除出构建（已隔离至 `.ai/legacy/preserved/`）

## BLOCKED 唯一触发条件

必须访问项目根目录外；必须获得真实 secret 且 mock 无法替代；必须处理未经授权的真实未成年人数据；必须外部发布/部署；同一关键失败连续 5 轮修复仍无法消除。
触发时输出 BLOCKED.md。普通产品歧义不暂停——选最小安全可验证方案并记入 DECISIONS.md。

## 产品硬约束

- AI 只建议（学科/章节/知识点/题型/错因/复习价值）+ 置信度；学生完成最终错因反思
- 工作日完全离线、无屏幕
- 看懂 ≠ 当场会做 ≠ 延迟独立做对（三种状态必须区分）
- 北极星指标不是收录量/对话次数/打开次数
- 支持“不值得长期保留”归档
- 数据最小化；未成年人数据去标识化；不默认用于训练
- 所有 AI 结论显示置信度；低置信度进入人工校正
- 先最小闭环，再考虑知识图谱/变式题/复杂家长端
