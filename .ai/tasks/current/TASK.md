# TASK — Super Error Log MVP 自主构建

## 使命

从零构建一个可本地运行的中文响应式 Web MVP，服务工作日不能使用电子设备的初三住校生：

> 用尽量低的周末维护成本，把纸质错题转化为工作日可执行的延迟独立重做任务，并用行为证据而不是熟悉感判断掌握。

## 核心闭环（必须完整）

周末批量上传纸质错题（图片/PDF）
→ mock/真实 AI 切分与结构化（低置信度人工校正）
→ 学生完成四项最小反思（AI 不得代写）
→ 系统按可解释规则从 ~20 题选 5–8 题
→ 生成 A4 黑白可打印复习包（题目/答案分离、演算空间、短 ID）
→ 学生在校离线完成
→ 下周末回传结果（独立做对/提示/做错/未完成）
→ 更新掌握状态与下次复习调度
→ 趋势视图（学生详细 / 家长聚合，私人反思隔离）

## 已确认用户事实（不得再提问）

- 广州执信中学初三住校生，成绩前 20%，目标保持高分
- 工作日禁止电子设备；周末可拍照录入；错题几乎全纸质，每周约 20 道
- 来源：纸质作业/练习册/周测月考模拟/课堂临时题/课外题，大致均布
- 通常有标准答案、教师批注、学生原始解题过程
- 当前流程：老师讲解后原卷订正或抄答案；整理后不知何时复习；复习=重看答案
- 首批学科：数学、物理、化学
- 学生坚持错因反思必须自己完成
- 家长可看薄弱知识点；学生保留私人复盘空间
- 第一版：周末批量录入 + 可打印工作日复习包，工作日不用 App

## 执行协议

Loop Engineering：INSPECT → MODEL → PLAN SMALL → FAILING TEST → SMALLEST SLICE → NARROW TEST → OBSERVE → CRITIQUE → REPAIR → WIDER TESTS → DOCUMENT → CHECKPOINT。
每轮一个可验证小切片；事实分级 CONFIRMED / LIKELY / UNKNOWN；同一失败最多 5 轮且每轮换根因假设。
