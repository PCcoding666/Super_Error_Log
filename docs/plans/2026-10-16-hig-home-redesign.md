上一轮仅调整通用样式，首页仍将所有步骤平铺，当前任务与辅助入口相互争抢。这次交付首页结构、根导航和安排面板的实际改动，并与上一轮 `e279827` 对照。生产应用和学生数据不参与预览发布。

## 依据与平台边界

实际读取并使用 [Apple Design Skill](https://github.com/dickwu/apple-design-skill/blob/914b6a377c22755597e4405e54911b996de822d7/SKILL.md)，固定提交 `914b6a377c22755597e4405e54911b996de822d7`；本机位置 `/workspace/shared/design-skills/apple-design`。本项目是 React SSR 移动网页，不声称实现 UIKit 或通过原生 HIG 认证。CSS 像素不是原生 pt；44 CSS px 为本项目触控目标，文字使用 rem 和系统字体栈，验证浏览器放大，不称为原生 Dynamic Type。采用自绘一致的 SVG，不分发 SF 字体或 SF Symbols。

## 页面与交互

屏幕目的：让学生知道现在该做哪一步，完成周末数字整理，随后回到纸上延迟练习。

首页由大标题、简短周节奏说明、当前任务及其操作、本周安排入口、学习记录组成。清晰的当前任务与真实周进度是本产品的识别点，不添加虚构连续天数、奖励或装饰性数据。完成态与周中态继续解释纸上独立练习和下周录结果。安装提示收起为辅助说明。

```text
紧凑宽度                    常规宽度（内容列不无限拉长）
今天              设置      今天                         设置
周末 · 拍卷子、准备练习      周末 · 拍卷子、准备练习
┌ 当前任务 ──────────┐      ┌ 当前任务 ──────────────────┐
│ 任务标题／真实说明   │      │ 标题、说明、真实进度          │
│ [主要行动] 次要行动 │      │ [主要行动] 次要行动           │
└───────────────────┘      └────────────────────────────┘
本周安排          ›         本周安排                    ›
学习记录                    学习记录
今天    错题    练习         今天          错题          练习
```

网页优先使用原生链接、表单、details 和 dialog；不迁移为 SPA，不改变上传转换、重试、幂等、隐私、AI 权限、延迟掌握判定或 A4 版式。圆角为渐进增强；普通 CSS 圆角作为兼容回退是实现选择，不宣称被 HIG 禁止。

## 颜色与排版参数

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F2F2F7` | `#000000` |
| 内容表面 | `#FFFFFF` | `#1C1C1E` |
| 正文 | `#1C1C1E` | `#F5F5F7` |
| 次要文字 | `#63636B` | `#AEAEB5` |
| 交互强调 | `#0066D6` | `#64AAFF` |
| 次级交互表面 | `#EDF4FF` | `#172B44` |

按 WCAG 相对亮度公式计算：浅色正文／内容表面17.01:1，次要文字／页面5.33:1，蓝字／白色5.42:1，蓝字／页面4.86:1；深色正文／内容表面15.63:1，次要文字7.71:1，蓝字7.08:1，按钮深色文字／蓝底7.05:1。以上是指定色对的结果，不代替所有图片和透明叠加场景的逐像素审计。

字体使用系统栈；显示标题2.125rem、任务标题1.75rem、分组标题1.375rem、正文1.0625rem、辅助0.9375rem／0.8125rem、导航0.75rem。默认根字号16px，对应34／28／22／17／15／13／12px。面板入场240ms、淡出180ms，减少动态时停用；短拖可取消，长拖或明确关闭返回原位置。

## 验收与交付

1. 根导航与面板有实际功能、键盘操作和无脚本回退。
2. `npm run verify` 和预览脚本类型检查通过。
3. 用真实 SSR 合成数据导出上一版／新版，在同场景、同尺寸、同外观下截图；独立审查首页视觉及关键交互。
4. 更新现有私有预览站，记录代码提交、技能应用、截图和验证结果。
