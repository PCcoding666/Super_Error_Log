# PRODUCT SPEC — 产品形态与关键交互

版本：v1.0（2026-09-05） 与 PRD v1.0 一致

## 1. 信息架构

```
/                        首页（周末仪表盘：本周批次、待办、下周计划入口）
/onboarding              首次设置（匿名档案、学科、隐私说明）
/batches                 批次列表
/batches/:id             批次详情（处理进度、文件状态、重试）
/batches/:id/review      低置信度校正
/items                   错题列表（筛选：状态/学科/知识点）
/items/:id               错题详情（图片、字段、AI 建议、反思）
/reflect?batch=:id       逐项最小反思向导
/plan                    本周复习计划（评分+理由、5–8 题确认）
/packets/:id             复习包预览与 PDF 下载/打印
/packets/:id/return      下周末结果回传（快速录入 + 完成页匹配）
/trends                  趋势（薄弱知识点、错误模式复发、掌握趋势）
/parent                  家长聚合视图（只读）
/settings                设置（档案、学科、AI 服务模式、数据管理）
```

角色：匿名学生（默认全功能）与家长（仅 `/parent` 聚合）。MVP 为单机单档案：通过视图入口与 API 作用域隔离数据，家长视图不能访问反思与原图。

## 2. 通用设计约束

- 中文 UI；周末流程手机优先（单列、大触控目标 ≥44px），桌面自适应。
- 所有 AI 输出一律呈现为「建议 + 置信度 + 可修改」；禁止不可更改的事实化呈现。
- 学生反思必须由学生主动触发并确认提交；不存在 AI 自动保存反思的路径。
- 每个页面定义 loading / empty / error / partial / low-confidence 状态。
- 关键破坏性操作（删除批次、归档题目）需二次确认。
- 键盘可操作；表单控件有关联 label；错误提示与字段关联。

## 3. 页面规格

### P1 首次设置 `/onboarding`
- 用户目标：3 分钟内完成可用配置。
- 入口：首次访问任意页面重定向。退出：完成三步或显式跳过（学科默认全选）。
- 字段/步骤：① 昵称（可虚构，必填，仅本地展示）+ 学段固定「初三」；② 学科多选（数学/物理/化学，默认全选）+ 周末处理提醒偏好（周六上午/下午/晚上，仅本地提示，无推送）；③ 隐私边界说明页（家长可见范围、数据仅存本地、不用于训练），需勾选「我已了解」。
- 操作：完成设置。
- 状态：loading（创建中）；error（创建失败可重试）。
- 成功后数据变化：创建 StudentProfile + GuardianViewPolicy（默认聚合）。
- 可观测事件：`onboarding_completed`。
- 测试：J1 E2E。

### P2 首页 `/`（周末仪表盘）
- 用户目标：一眼看到本周该做什么。
- 展示：本周批次卡（状态/进度）；待办清单（待校正 n、待反思 n、待生成复习包、待回传）；最近一次复习包入口；趋势摘要条。
- empty：无批次时显示「上传本周错题」引导。
- 测试：J1/J2 E2E 覆盖。

### P3 批次列表 `/batches`
- 展示：批次号、创建时间、文件数、状态（processing/needs_attention/done/failed）、提取题目数。
- empty：引导上传。
- 测试：集成测试。

### P4 批次详情 `/batches/:id`
- 用户目标：知道处理进展、哪些文件有问题。
- 展示：每个文件的状态（queued/processing/done/failed/unsupported/too_large/duplicate）、识别出的题目数、失败原因与「重试」按钮；整体进度条。
- 操作：重试失败文件；删除批次（二次确认）；进入校正。
- 状态：partial（部分成功）明确显示；error 文件不阻塞其他文件。
- 事件：`batch_retried`。
- 测试：J2/J7 E2E；幂等集成测试。

### P5 低置信度校正 `/batches/:id/review`
- 用户目标：快速修正 AI 不确定的条目。
- 展示：仅列出低置信度/需确认条目；每条显示裁剪图、AI 建议字段（学科/章节/知识点/题型）与置信度徽章；可编辑；可标记「这不是错题/是重复」。
- 操作：保存本条并下一条；全部确认后进入反思。
- 状态：全部确认后显示完成态；无低置信度条目时自动跳过。
- 规则：校正后条目状态 → ready_for_reflection。
- 测试：J2 E2E；校正 API 集成测试。

### P6 错题列表 `/items`
- 展示：短 ID、学科、知识点、状态徽章、错因、复习价值评分；筛选（状态/学科）；搜索知识点。
- 操作：进入详情；批量归档（二次确认）。
- empty：引导上传。
- 测试：集成测试。

### P7 错题详情 `/items/:id`
- 展示：原题图、原始解题图、教师批注/答案图（可切换）；结构化字段（学科/章节/知识点/题型，可编辑）；AI 建议区（建议值+置信度+「采用」按钮）；状态时间线；反思区（学生）；掌握状态与下次复习时间。
- 操作：编辑字段；查看/编辑反思（学生视图）；归档。
- 家长视图下此页不可访问（403 重定向）。
- 测试：J3/J8。

### P8 最小反思向导 `/reflect?batch=:id`
- 用户目标：每题 ≤ 30 秒完成四项确认。
- 展示：一题一屏：题图 + 四个问题（做单选/点选）：
  1. 做题状态：完全不会 / 知道考什么但没想到方法 / 方法基本正确但步骤出错 / 本来会但审题计算书写失误 / 时间不足 / 其他
  2. 主要错因：知识概念 / 方法选择 / 推理步骤 / 计算 / 审题遗漏 / 表达规范 / 时间注意力状态
  3. 当前掌握感：0 仍不会 / 1 看提示可能会 / 2 现在重做应该会 / 3 隔几天也有把握
  4. 复习价值：必须再做 / 可以再做 / 没必要再做
- AI 建议以「参考」形式预展示但不预选（不自动提交）；学生必须亲自点选后「确认，下一题」。
- 进度：第 x / n 题；可中途退出，进度保留（逐题保存）。
- 成功后数据变化：ErrorDiagnosis 记录创建；条目 → eligible_for_review。
- 事件：`reflection_submitted`。
- 测试：J3 E2E；「无 AI 自动提交」单测（API 不接受来源为 ai 的反思提交）。

### P9 本周复习计划 `/plan`
- 展示：系统按评分排序的候选列表（每题：评分、理由文案、知识点、错因）；默认勾选 Top 5–8；学生可增删（保持 5–8 区间，UI 限制）；冲突提示（「你认为没必要，但同类错误近期复发」）。
- 操作：确认计划 → 生成复习包。
- empty：eligible 不足时提示并允许全部纳入。
- 成功后：创建 ReviewPacket（scheduled）。
- 测试：评分规则单测；J4 E2E。

### P10 复习包预览与打印 `/packets/:id`
- 展示：题目清单（短 ID、学科、知识点）；「下载 PDF」「打印」按钮；版式说明。
- PDF 规范见 §5。
- 成功后：packet → packet_generated（记录生成时间）。
- 测试：J4 E2E + PDF 程序检查。

### P11 结果回传 `/packets/:id/return`
- 用户目标：3 分钟录完一包结果。
- 展示：两种模式：① 上传完成页照片 → 系统按短 ID 匹配（匹配置信度显示，失败可手动指定）；② 快速录入列表：每题两个点选（完成情况：独立完成/做出但不确定/使用提示/完全不会/未完成；结果：做对/做错）+ 可选「卡住的步骤」。
- 操作：提交回传。
- 成功后：每题创建 ReviewAttempt + MasteryEvent；状态机流转；下次计划候选更新。
- 测试：J5/J6 E2E；状态机单测。

### P12 趋势 `/trends`（学生视图）
- 展示：薄弱知识点 Top N（按复发与错误频次）；错误模式复发列表（「近 3 周『计算』错因出现 5 次」）；掌握趋势（各状态题目数量随时间）。
- 测试：J6 E2E。

### P13 家长视图 `/parent`
- 展示（仅聚合）：本周任务完成率；各学科掌握趋势；薄弱知识点 Top 5（名称+次数，无题目原文）。
- 明确不可见：错题图片、题目原文、反思任何字段。
- 直接访问学生 API/页面被拒绝。
- 测试：J8 权限 E2E（页面 + API 双层）。

### P14 设置 `/settings`
- 展示：档案信息；学科；AI 服务模式（mock / OpenAI-compatible，显示当前模式与状态，不显示 Key 本体）；数据管理（导出/清空，二次确认）。
- 测试：集成测试。

## 4. 端到端用户流程（与 J1–J8 对应）

```
首次设置 → 上传批次（20 题 fixture）→ 进度 → 低置信度校正 →
逐题四项反思 → 计划页确认 5–8 题 → 生成 PDF →（工作日线下）→
回传结果（四种结果各至少一题）→ 状态更新 → 趋势/下次计划 → 家长视图检查
```

## 5. 打印复习包版式规范（强制）

- 纸张 A4 纵向；黑白友好（不依赖彩色传达信息；对比度 ≥ 4.5:1）。
- 结构：封面（学生昵称、周次、生成日期、题目数量、使用说明）→ 题目页（每题一页起始，禁止题目跨页断开；题干大图清晰）→ 每题演算空白区（≥ 页面 1/2）→ 提示区（可选，折叠在答案部分之前）→ 末页答案区（与题目分离，可裁开；按短 ID 索引）。
- 每题元素：短 ID（如 `M-03`）、计划完成日期、学科/知识点、结果勾选框（□ 独立完成 □ 使用提示 □ 做错 □ 未完成 + □ 做对 □ 做错）。
- 题目页**不得出现**标准答案与学生原始错误答案图片。
- 公式、图形、单位必须可读（渲染为文本/矢量或高分辨率图）；汉字清晰。
- 页边距 ≥ 15mm；页脚页码；适配普通家用/学校打印机（无边距打印不依赖）。
- 程序检查项：A4 尺寸；答案区文本不出现在题目页；每题短 ID 存在；页数 ≥ 题数。

## 6. 空 / 错误 / 低置信度状态汇总

| 场景 | 表现 |
|---|---|
| 无批次 | 首页/批次页引导上传 |
| 批次处理中 | 进度条 + 可离开（后台继续） |
| 部分文件失败 | 文件级错误 + 重试；其余正常 |
| AI 超时/非法 JSON | 条目标记「识别失败」，可重试或手动录入 |
| 低置信度字段 | 黄色置信度徽章 + 进入校正队列 |
| 无 eligible 题目 | 计划页说明 + 引导先完成反思 |
| eligible < 5 | 全部纳入并提示本周题量偏少 |
| 回传匹配失败 | 列出未匹配页，手动指定题目 |
| 家长访问受限页 | 403 页 + 返回家长视图 |

## 7. 可观测事件（最小集）

`onboarding_completed`、`batch_created`、`batch_file_failed`、`batch_retried`、`item_corrected`、`reflection_submitted`、`plan_confirmed`、`packet_generated`、`attempt_submitted`、`mastery_changed`、`parent_view_accessed`。
事件不含反思文本与图片内容。

## 8. 响应式与无障碍

- 断点：手机 < 640px 单列；≥ 640px 双列；≥ 1024px 桌面布局。
- 触控目标 ≥ 44px；表单自动放大输入字号防 iOS 缩放。
- 全键盘可达；焦点可见；图片有 alt；错误提示 `aria-describedby` 关联。
- 打印样式使用独立 print stylesheet/PDF 生成，不依赖屏幕样式。
