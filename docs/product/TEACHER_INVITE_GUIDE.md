# 老师发码指南：让学生扫一下就用起来

适用对象：给学生发邀请码的老师，以及帮老师在服务器上生成邀请码的管理员。写于 2026-11-01，对应「预填邀请码的登录链接与二维码」上线后的行为；流程变了请同步改这份指南。学生自己怎么用错题本见[学生使用指南](STUDENT_GUIDE.md)。

## 一句话

每个学生一枚 12 位邀请码。老师把**带码的链接**或**二维码**发给学生，学生打开就是已经填好码的登录页，点一下「进入我的错题本」就能用，不用抄码、不用手敲。

链接长这样（码是示例）：

```
https://study.pccoding666.com/s/?code=ABCD-EFGH-JKMN
```

二维码里的内容就是这条链接。**码、链接、二维码三样东西是等价的**：谁拿到其中任何一样，60 天内都能进这个学生的错题本。所以一对一发，不要发到群里。

## 一、管理员怎么生成（服务器上，一分钟）

在服务器上，用服务账号运行管理命令（必须带 `SEL_STUDENT_HOST_DIR`，值和运行中的服务一样）：

```bash
sudo -u supererrorlog env SEL_STUDENT_HOST_DIR=/var/lib/super-error-log/student-host node dist/studentHost/admin-cli.js create --qr
```

屏幕上会依次出现三样东西，**只显示这一次**，不写日志、不落盘：

1. 学生账号编号和邀请码（`XXXX-XXXX-XXXX`）；
2. 登录链接（`https://study.pccoding666.com/s/?code=…`）；
3. 一个黑白方块组成的二维码（`--qr` 才有），手机相机直接能扫。

常用命令：

| 要做什么 | 命令 | 说明 |
| --- | --- | --- |
| 新建一个学生并发第一枚码 | `create --qr` | 一次一个学生。学生也可以自己在登录页「注册账号」（姓名、手机号、自设 4 位找回码）拿码，不一定要管理员建；服务开了班级注册码（`SEL_REGISTRATION_CODE_REQUIRED=1`）时还要老师给的注册码。 |
| 给已有学生再发一枚码 | `invite <学生ID> --qr` | 旧码继续有效。 |
| 学生忘了码、怀疑码泄露 | `reset-invitation <学生ID> --qr` | 旧码和所有已登录的手机**立刻失效**，学习记录不变。先核对本人。 |
| 找学生 ID | `lookup <姓名> <手机号>`，或 `lookup <姓名片段>` / `lookup <手机尾号 4 位>`，或 `list` | 都不显示邀请码。 |

小贴士：

- 不加 `--qr` 只打印码和链接；把链接贴进任何二维码生成工具也能得到同一个二维码。
- 终端里的二维码可以直接截图发给学生，或打印出来；它强制黑字白底，和终端配色无关。
- 公网入口不是 `study.pccoding666.com` 时，加 `--origin https://你的域名`，或在环境变量里设 `SEL_PUBLIC_ORIGIN`。入口写得不对命令会先报错，不会发出没法用的码。

## 二、老师怎么发给学生

三种方式任选，**都是一对一**：

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 二维码 | 把终端里的二维码截图或打印出来，当面让学生用手机「相机」对着扫，点屏幕上弹出的链接 | 班里当面发 |
| 链接 | 把登录链接私聊发给学生（或家长） | 远程发 |
| 只给码 | 把 12 位码告诉学生，学生在 `https://study.pccoding666.com/s/` 手动输入 | 对方只能收文字 |

注意：

- 一个学生一枚码，不要两个学生共用（共用等于两个人看同一本错题本）。
- 链接和二维码里就是这枚码，**不要发到班级群**。发错人了，马上让管理员 `reset-invitation`。
- 码 60 天有效、期间可以重复登录。快到期时学生自己在「设置 → 我的邀请码」里一键换新码，不用找管理员。

## 三、学生第一次打开会看到什么

1. 扫码或点链接 → 打开的是登录页，输入框里**邀请码已经填好**，页面写着「邀请码已经从链接里填好了，点下面的「进入我的错题本」就行」。
2. 点「进入我的错题本」→ 选学段（初中或高中）。
3. 到了错题本首页，点「去拍照」，拍一张老师批改过的卷子。做错的题会收进错题本，接下来按[学生使用指南](STUDENT_GUIDE.md)的节奏走。

重要：**打开链接不等于登录。** 只有学生点了「进入我的错题本」才算登录。微信、QQ 给链接生成预览、学生不小心点开又关掉，都不会把码用掉，也不会把别人登进去。

## 四、学生在微信里打开怎么办

微信（或 QQ 等）里可以先用。但「放到手机桌面」和「打印练习」要换到浏览器才行，而且微信里登录过的状态到了浏览器里不通用。登录页顶部会直接给出步骤：

1. 点右上角「…」；
2. 选「在浏览器打开」（iPhone 上叫「在 Safari 中打开」，有的手机叫「用浏览器打开」）；
3. 在浏览器里再点「进入我的错题本」。

找不到「在浏览器打开」的，点页面上的「复制网址」，粘到浏览器地址栏打开——复制的网址里已经带着邀请码，到了浏览器还是填好码的登录页。

## 五、放到手机桌面（推荐做一次）

放到桌面以后像 App 一样一点就开，不用每次找链接。要在浏览器里做（微信里做不了）。学生在「设置 → 添加到主屏幕」能看到同样的步骤：

- **iPhone · Safari**：用 Safari 打开 → 点底部「分享」（方框加向上箭头）→ 往下找「添加到主屏幕」→ 点右上角「添加」。
- **安卓 · Chrome**：用 Chrome 打开 → 点右上角「⋮」→「添加到主屏幕」（有的叫「安装应用」）→「添加」。安卓上桌面图标打开的仍是浏览器页面，这是有意的——不这样拍照和相册就选不了文件。

从桌面图标打开如果要求登录，重新输入邀请码或再扫一次二维码就好，学习记录都在。

## 六、换手机、忘了码、怕码泄露

| 情况 | 怎么办 |
| --- | --- |
| 换手机 | 旧手机：设置 → 我的邀请码，页面上有这枚码的**登录链接和二维码**；用新手机的相机扫一下，或把链接发到新手机，打开点「进入」。 |
| 忘了码，手机也没登录着 | 登录页点「忘了邀请码？找回」，填注册时的姓名、手机号和 4 位找回码，当场换一枚新码（旧码作废）。管理员建的账号没有找回码，找管理员 `reset-invitation`。 |
| 怕码泄露 | 学生在「我的邀请码」里点「重新生成邀请码」，或管理员 `reset-invitation`。旧码和其他手机的登录立刻失效。 |
| 已经登录着别人账号的手机扫了新码 | 会看到填好码的登录页，并提示「进入后会换成这个邀请码的错题本」；点「进入」才换，不点不变。 |

## 七、隐私：码会出现在哪里，为什么不怕

- 码只出现在：链接的 `?code=` 里、登录页的输入框、微信页面的「复制网址」按钮、「我的邀请码」页（只有登录着的那台手机）、管理员终端里显示的那一次。
- 服务器**不记录带码的网址**：应用的访问日志只记页面路径，不记问号后面的内容；前面的反向代理没有开访问日志。
- 打开链接只是看页面，不建立登录、不计入输错次数；点按钮才兑换。
- 页面不会把带码的网址发给别的网站（Referrer-Policy 为 same-origin）。
- 最大的风险不在技术上，而在**群发**：谁拿到链接谁就能进这个学生的错题本（60 天内）。一对一发；发错了立刻换码。

## 八、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 扫码后页面说「链接里带的邀请码不完整」 | 二维码或链接被截断、复制少了几位。重新发，或让学生手动输入 12 位码。 |
| 「这个邀请码进不去」 | 码输错、已过 60 天、或已被换掉。先对照；不行就找回或找管理员。 |
| 「试得太频繁了」 | 同一枚错码 10 分钟内输错 10 次会被挡 10 分钟左右，只影响这枚码，不影响其他同学；正确的码不受影响。 |
| 安卓从桌面图标打开后相册点不开 | 旧版本桌面壳的问题，页面会提示换手机浏览器打开；现在安卓的桌面图标打开的是浏览器页面，不会再出现。 |
| 学生在微信里登录了，换到浏览器又要登录 | 正常。微信和浏览器是两个独立环境，用带码的链接或二维码再点一次「进入」即可。 |
