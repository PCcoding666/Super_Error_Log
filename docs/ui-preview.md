# 手机网页前后对照

生成器分别加载两个 checkout 的真实 React SSR 组件和 `STYLES`，使用同一组合成数学题、照片与固定日期 `2026-10-17T02:00:00.000Z`。不启动应用、不读取数据库，也不向生产服务发请求。旧版 DOM 来自旧版组件。

```sh
# HIG 重设计与上一轮 e279827 的干净 checkout 对比。原始 4317be8 快照仍保留。
npm run ui:preview -- \
  --before /workspace/Super_Error_Log-ui-v1 \
  --after /workspace/Super_Error_Log \
  --out /workspace/Super_Error_Log-ui-preview/dist

# 静态托管；浏览器打开 http://127.0.0.1:3188/
python3 -m http.server 3188 --bind 127.0.0.1 \
  --directory /workspace/Super_Error_Log-ui-preview/dist
```

Node ≥24。无需新依赖。也可直接用 `npx tsx scripts/ui-preview/generate.ts` 加同样参数。输出目录应在 checkout 外或其忽略的 `dist/` 内；非空目录只有带本工具 manifest 时才可覆盖。

生成后可重复制作同尺寸截图和选题→文字追问的演示录屏（需要已安装 Playwright Chromium，且上面的静态服务正在运行）：

```sh
npm run ui:preview:check
npm run ui:preview:capture -- \
  --url http://127.0.0.1:3188 \
  --out /workspace/Super_Error_Log-ui-preview/dist/evidence
```

产物包括 30 张页面截图（含新版浅深色安排面板）、浅深色并排对照图、两段 WebM 录屏和 `evidence/index.html` 图集。捕获脚本只接受本机静态预览地址，检查没有页面错误或外部/非 GET 请求。重新运行生成器会清除旧输出，因此应先生成页面，再捕获证据。

`dist/index.html` 是对照入口，`before/`、`after/` 是各版本实际页面，`assets/` 是公共的演示适配器及合成 SVG。每个版本的 `assets/` 保留自己的 CSS 和图标。可独立复制整个输出目录静态托管；不要只复制入口页面。

入口提供 390×844、320×740、430×932 尺寸，浅色/深色/系统外观、200% 文字、减少动态和单独打开链接。电脑并排显示；手机可切换版本。画面按可用宽度等比缩放，内部保持所选手机尺寸；容器高度随缩放调整，不必横向滚动。调整浏览器宽度或切换显示版本不会重载已打开的页面。页面内导航保留外观参数；两侧交互相互独立，重选场景会对齐。

导出场景：邀请码登录、今天、上传说明、拍照、识别状态、勾出错题、题目列表、题目详情、选题、追问、确认错因、设置、主屏幕说明。`manifest.json` 记录两个来源的完整 commit、dirty 标记和路径、tracked diff 摘要、CSS 摘要、组件文件、原始 SSR 摘要、固定日期、fixture 摘要及场景路径。工作区有未提交修改时，commit 自身不代表全部来源，需结合 dirty 信息。

演示交互限定在独立的 `scripts/ui-preview/demo.js`：

- 原生勾选、单选、文字输入、折叠展开；选题数量、上下限和提交按钮文字反馈。
- 登录接受任意非空演示文字并进入合成今天页；退出返回演示登录。不兑换邀请码、不建立真实会话。
- 上传同意、选题、勾题和文字回答切换到预设的下一场景。不会改变合成识别或 AI 建议，页面会解释这一点。
- 设置和回答可记在当前标签页的 `sessionStorage`，版本间隔离；浏览器禁止存储时明确提示。没有服务器保存。
- 照片输入可显示本机选择的图片和文件名，使用临时 blob URL；不上传、不转码、不识别、不保存。继续时显示预设的合成识别状态。
- 录音、打印、结果记录、题目修改等未实现的服务动作会显示明确提示，不发送请求。

导出时移除原应用 `CLIENT_SCRIPT`、Service Worker 入口、manifest、自动刷新与语音 endpoint；表单 action 改为页内锚点，应用链接改为本地场景或提示。CSP 禁止网络连接与表单提交，独立演示适配器负责服务动作演示；新版还复用实际网页的 `UI_SHEET_SCRIPT`，仅处理本周安排的 dialog、焦点和关闭手势，无网络及存储。旧版不补造这个交互。实际 SSR 后仅做这些静态资源/行为适配和同一份预览提示，不重新拼装应用内容。深色/浅色 CSS 变体只替换来源 CSS 的系统外观 media 条件。

生成器检查 HTML 的本地链接及素材是否存在，拒绝输出应用脚本、自动刷新或外部资源。生成步骤在干净临时 cwd、最小 mock 环境中启动两个独立进程，避免读取 checkout 下的 `.env`，并确认没有写入临时数据。输出只含合成页面、CSS、图标、SVG、演示脚本和来源信息，不含应用源码。

浏览器验收时检查入口场景切换、两侧直接链接、原生输入与计数、演示提交、设置刷新、图片本机显示、未支持操作提示；确认请求均在静态预览源内且没有 POST/fetch/Service Worker。再检查浅/深色、窄屏、200% 文字、键盘焦点、减少动态，以及滚动到最后一项后仍能看见内容与底部操作。截图和录屏由协调者保存。此静态工具不证明真实 AI、上传、录音、打印或学习记录服务正常；这些继续由应用现有测试和真机验收负责。
