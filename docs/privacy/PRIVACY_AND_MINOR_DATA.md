# 隐私与未成年人数据说明

## 数据最小化

- 只需昵称（可用化名），不收集姓名、学校、联系方式。
- 上传内容仅限错题照片/PDF；EXIF 元数据（含可能的 GPS 信息）在入库前被 sharp 剥离并统一转 JPEG。

## 角色隔离

- 两个角色：学生（默认）与家长，通过 `sel_role` Cookie 切换。
- **重要边界**：角色为自声明、无口令（MVP 家庭自用单机假设，决策 D6）。该机制防误触、不防有意绕过——家长手动切回学生态即可看到全部内容。若试点中出现绕过行为，下一步加家长口令。
- 学生专属：题目原文、照片、反思、回传明细、媒体文件流。家长态访问一律 403（页面与 API 双层）。
- 家长可见：每周完成率、学科掌握度、薄弱知识点 Top5 —— 全部为聚合数字与标签名。

## AI 边界

- AI 只做：题目提取、字段建议、回传照片匹配。
- AI 不做：提交反思（服务端校验 `submittedBy='student'`，AI 提交直接拒绝；反思页的「一键采纳」是学生本人点击提交的主动行为，记录 `adopted_ai=1` 供采纳率监控）、自动归档、评价学生。
- mock 模式不发出任何网络请求；真实模式仅向配置的模型接口发送题目图片/文本。
- 掌握感（0–3 自评）永远不进入 AI 建议范围——它是「自评 vs 延迟重做结果」的校准信号，AI 代建议会污染该信号。

## 云端识别链路（iOS → study.pccoding666.com，2026-09-20 起）

- **上传前明示同意**：iOS 每批上传前展示所选照片张数与处理链路说明，不同意则不上传；照片原始字节只存本机，上传的是一次性生成的 JPEG 副本。
- **设备授权**：扫码配对（配对码单次使用、5 分钟有效）；兑换得到 30 天设备令牌，存本机 Keychain；管理员可随时按设备撤销（撤销后该设备请求一律 401）。
- **传输与入口**：全程 HTTPS（Let's Encrypt）；服务端有按设备限流、上传并发与容量门槛、磁盘水位门槛；无令牌一律 401。
- **服务器存储**：识别任务的原图与裁图存于广州 ECS `/var/lib/super-error-log`（专用系统用户私有目录，0750）。**当前无自动过期清理**——数据量受磁盘门槛保护；试点期如需清理，由管理员手动删除任务目录（数据保留策略待试点后拍板，见 RISK_REGISTER）。
- **第三方处理**：图片由阿里云百炼（DashScope 兼容接口，base64 内联提交，不走临时 OSS）做识别处理；服务商的数据处理以其条款为准，上传同意文案已告知学生/家长。
- **可核对性**：iOS 端任何 AI 识别结果必须对照本机原图逐项确认后才生效；服务器对未通过证据核对的内容不放行确认与打印。

## 存储与删除

- Web 端全部数据在本地 `SEL_DATA_DIR`（SQLite + uploads/ + packets/）。
- 事件日志（audit_event / events.log）只记录动作与实体 ID，不记录题目内容或反思文本。
- 设置页"清空所有数据"物理删除数据库记录与上传文件，不可恢复。
- iOS 端：照片与本机识别快照仅存设备本地（应用沙盒，排除云备份）；云端任务的删除走管理员通道。
