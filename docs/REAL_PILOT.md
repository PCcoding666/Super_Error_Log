## 当前已实现

- 所有真实提取都需人工校对。校对页可改完整题干、作答归属和框坐标，并排除非错题候选；复杂增删框目前使用高级 JSON 编辑，尚无拖拽框 UI。

- 计划实际使用评分和知识点分布选题；回传单独记录纸上实际作答日期，不把延迟上传当作延迟重做；重印不重置首次打印日期。
- 新资产记录 mock/openai/bailian 来源；旧来源不明且无证据的条目被阻止进入真实反思/选题/打印。建议在独立 `data/real` 数据目录重建真实试点，不删除旧库。
