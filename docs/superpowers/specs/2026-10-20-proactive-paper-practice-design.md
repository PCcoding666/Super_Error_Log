# 主动安排与纸上练习闭环

用户于 2026-10-20 确认本设计方向，并授权开发、验证后直接合并。基于最新 `origin/main`（`ffb4349`），不从交接文档中的旧分支开发。当前主分支已有逐题手写上传与转写、独立的打印路径；本轮复用这些能力。

## 目标与范围

设备使用时间受限的学生打开练习页即可知道练什么、怎样做、交到哪里。默认路径：

**查看系统建议 → 接受本次练习 → 看题／可选打印 → 白纸作答 → 拍照交练习 → 查看并确认反馈。**

保留自选、换题、暂缓、取消、手动核对。照片可以含多题或一道题跨多页；支持多次补交。iPad 白板、变式生成、外部题库本轮不做。

## 任务与首页

- 首页 GET 只读，不创建任务、不发模型请求。无当前任务时展示规则推荐、题量与真实推荐理由；默认最多 3 题，可通过现有选题页选择 1–8 题。
- 接受推荐通过 POST，使用请求标识保证重试幂等。选择后冻结题目与理由；新建后默认进入看题，不先进入错因追问。
- 有未完成任务时优先显示最早的仍在进行的任务，清楚展示“查看题目”和“拍照交练习”。历史记录折叠，暂缓任务可恢复。完成后的任务展示结果与下一步。
- 暂缓保留任务与占用，取消保留历史及已记录结果并释放未作答题；取消任务不能继续写入作答或改变掌握状态。旧任务可以正常读取。
- 练习任务状态、照片收到情况、结果记录、掌握状态分别表达。没有照片不能推断未做题。

## 题目与纸张

- 使用现有冻结的安全题面快照，同时支持手机看题和打印。打印不是提交前提；生成题面不等于打印成功。
- 默认答案不出现在题面。原作答、订正、教师批注不作为练习题面。低置信的遮白裁图保留原有警示。
- 看题页说明白纸写“第 1、2、3 题”与过程，可随时拍照交练习。提示需主动打开并保留使用记录。
- 更换尚未完成任务先取消旧任务再选题；有已记录结果时，只释放剩余题，不改变已完成学习记录。

## 拍照、识别与初步反馈

- 新增整份练习的照片附件，永不登记成新错题。复用浏览器 JPEG 转换、串行上传、失败重试、请求幂等、服务器体积/像素/容量限制和鉴权。
- 每任务最多 12 张照片，每张上传最多 15 MiB；存储规范化 JPEG。成功照片立即持久化，失败不丢失其他照片。
- 完成上传后单独 POST 发起核对，页面可离开。全部照片与冻结题面一起交给分析器，避免按单页误判跨页答案。
- 分析器仅返回题号关联、可见作答、是否看清/完整、对错建议与简短反馈。不自动写反思、作答结果或掌握事件。
- 模型必须只关联本任务题号。无清晰题号或无法确认归属的作答保留为“待关联”，由学生一次选择题目；不得丢弃。
- 缺失、模糊、不完整、缺乏可用参考答案的结果不得形成确定对错。识别失败时仍可看照片、重试或手动核对。
- 照片版本随上传递增，旧异步响应不能覆盖新照片的反馈。重启中断可重试；并发重复核对只运行一次。每版本最多 3 次分析。
- UI 明确写“AI 初步核对”，学生看到可修改的建议。确定建议可一次确认；有疑问的题保持未记录，只要求处理不确定部分。

## 确认与学习记录

- 确认时显式填写实际作答日期和是否用过帮助，日期不能用拍照日期代替。允许按题覆盖日期/帮助。
- 通过既有 `submitReturns` / 状态机记录，保留提示下限、至少 3 天延迟等规则。AI 建议本身不产生掌握。
- 支持部分确认与重复提交幂等；未确认题保持待处理。新增照片不覆盖已记录的首次作答。
- 反馈优先呈现本次作答与具体建议，按已确认结果提供订正、补交或稍后复习入口。错因复盘保留为可选入口，不阻塞练习。

## 兼容与验证

- Node >= 24；TypeScript ESM、React SSR，无 hydration。
- 主交付为 `/s/` 手机网页，保留三入口与错题本筛选行为。不修改 iOS、部署流程、学生隔离或真实数据。
- 数据库只新增表，外键级联仅随既有记录删除；不破坏既有练习与照片。
- 合成数据覆盖：推荐只读与幂等，暂缓/取消及占用释放，多页关联、模型不确定/失败、上传重试、迟到响应、部分确认、提示与延迟规则、跨任务与跨学生访问。
- 浏览器覆盖完整纸上流程、无 JS 基本可用、320px/手机/iPad 宽度、深浅主题、批量部分失败与补交。
- 执行 `npm run verify` 与独立全分支代码审查；修复重要问题后 PR 到 `main`，检查通过直接合并并查看自动发布状态。
