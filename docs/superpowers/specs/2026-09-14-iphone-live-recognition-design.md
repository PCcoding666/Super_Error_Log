# iPhone 真实 AI 接入：让自己的照片进入复盘

日期：2026-09-14。状态：用户确认中文修改后明确要求“开始”，本说明已获准实施。主交互语言为中文，此要求取代此前原型的英文约定。尚未宣称实现或验收通过。

## 你会得到什么

学生在 iPhone 应用中导入照片，明确同意识别后，看到从这些照片提取的真实题目。选择值得复盘的题，完成自己的反思，再生成不泄露旧答案的纸质练习包。失败和看不清的题不会消失，也不会用预置题填充。

本轮使用 Mac 本地服务和 iPhone 模拟器。应用主交互统一使用简体中文，包括导航、按钮、复盘问题、上传说明、进度、错误提示和应用自有的无障碍标签；原题、原始作答和订正保留原语言。系统照片选择器、权限弹窗的系统按钮等跟随系统语言，不承诺覆盖系统文案。暂不部署云服务、不处理实体 iPhone 签名、不加入账户或多人同步。

三个主入口为 **本周**、**复盘**、**练习包**。应用生成的练习包标题、作答区标签和操作提示也使用中文；接口字段、内部状态标识、模型名称不因界面翻译而改名。

## 学生操作

1. **添加照片**：可导入最多 10 张。照片先保存在设备；仅导入不会上传。展示本次要发送的照片和说明“这些照片将发送至阿里云百炼进行 AI 识别。”，点击 **开始识别** 才开始发送。
2. **正在识别**：按照片显示已发现题数、已处理题数和失败题数，不伪造百分比。学生可离开页面；返回或重启应用后继续查看已保存任务。Mac 后端负责模型调用，不依赖手机持续保持页面打开。
3. **选择要复盘的题**：题目先作为候选展示，不能因为“识别成功”就宣称它是错题。可筛选 **有批改或订正** 和 **全部识别题目**；学生决定哪些值得复盘。**查看原图** 始终可用，支持缩放。
4. **有一处需要确认**：有关键歧义时，一次显示一个具体问题、对应原图位置，以及 **我也看不清**、**暂时跳过**。不要求学生辨认订正是谁写的，不把技术检查报告搬进主界面。
5. **复盘**：展示完整题干、必要图示、作答与订正的区分；学生填写原有四项复盘。AI 的证据说明标为 **AI 建议**，用中文表达，不代写反思、不推断学生心理。
6. **练习包**：学生主动选择已经完成复盘且通过打印检查的题。PDF 只包含题干、干净的必要图示和作答空间。没有干净图示或完整题干的题保留在应用中，明确说明暂不能打印。

预置的三道例题保留为独立 **示例题** 区，不与真实识别结果混合、不计入真实任务进度。已有例题反思和练习包继续可读。

## 接入方式

采用 **iPhone → Mac 本地后端 → 百炼北京地域**。不在手机放百炼密钥，也不让手机承担长时间模型请求。

- 在当前 TypeScript 项目增加独立的 mobile recognition 服务入口，复用现有图片处理、百炼客户端、证据结构和检查逻辑。默认仅监听 `127.0.0.1:3101`。
- 不直接复用网页角色 Cookie 作为移动端鉴权。移动端服务使用独立、随机的本地配对令牌；服务器文件限制访问权限，客户端存入 Keychain。令牌不等于百炼密钥，不打入安装包或日志。
- 本轮客户端只接受回环本地服务地址；不开放局域网、不创建公网隧道、不放宽任意 HTTP 访问。模拟器与 Mac 服务联调，实体设备连接留到后续明确授权的阶段。
- 真实识别服务拒绝 Mock 配置。认证、网络、模型权限或格式失败必须显式显示，不降级为演示数据。
- 使用独立本地目录 `data/mobile-recognition/`，测试与十图验收另建唯一目录。不会重置网页数据库、覆盖旧实验或迁移其未确认候选。

## 识别流程和接受条件

### 整页清单

从完整照片建立可见题目清单，记录题号、共享题干、小问、可见批改线索和边缘残缺情况。不能固定每页只取一题，也不能把每段手写当成一道新题。达到容量限制或发现边缘残缺时明确报告，而不是声称整页完整。

题号不是全局唯一键。同页左右页或不同章节题号重复时保留独立候选 ID 和页面位置，不能互相覆盖。

### 逐题提取

每题独立保存完整题干、必要图示候选、原始作答、订正、仍看不清的字符及来源位置。保存原图及其哈希、输入图片转换信息、提示版本、模型名称和调用记录。

提取模型可以读取完整原图，但返回的题框不因此被视为正确。定位、实际裁图完整性、裁图是否夹带邻题、转写匹配和人工确认是独立状态。显示在应用中的特写必须对应实际裁图；没有可靠特写时显示原图，不能用无意义裁框装饰结果。

必要图示从真实原图提取，不用生成图替代。只有图示完整且不带答案、订正污染时，才允许进入练习包。

### 校验与确认

自动检查先处理题干完整性、图示依赖、作答证据及裁框问题。针对定位不完整可执行有限次数的重新定位与实裁图校验，每次结果保留；不能修改历史失败为成功。

自动通过只表示机器检查通过。候选首次被学生选入复盘前，提供题干、原图和明确的 **确认，这是我要复盘的题** 操作；有关键不确定项时确认不能绕过它。学生无需阅读 JSON 或逐个审核技术指标。

个人归因仍由学生表达。AI 可提出引用真实作答的错误观察，例如“这一行把 9 + 4 写成了 16”，但证据不足时不得生成确定错因。原始错误不能被数学上更合理的答案替换。

## 任务、恢复和失败

- 上传完成就返回任务 ID，模型工作异步进行；客户端通过短请求获取状态。
- 每张照片、每一道题都有独立状态：等待、处理中、候选已生成、需要确认、失败或已跳过。
- 接口请求携带本地生成的幂等键。同一照片上传因断线重发时，返回原任务；相同键带不同内容应拒绝，而不是静默覆盖。
- 一个题目失败不回滚其他题目。重试只处理明确指定的失败阶段/题目；成功题的内容和 ID 不变。
- 网络、限流、暂时性服务错误允许最多两次自动重试；总共最多三次尝试。认证/权限/不支持模型立即停下，结构错误保留原响应并进入显式恢复，不无限重跑。
- 移动识别专用模型超时默认 30 分钟、可配置，与手机状态查询超时分开。不修改现有网页服务的全局超时。等待时展示真实状态，不承诺固定完成时间。
- Mac 服务重启后，已完成数据可读；未完成调用标记为中断，用户可以继续。不能因进程重启悄悄再次发起收费调用。
- 保存失败时不能向客户端宣称已接受任务或已完成。客户端只在本地结果保存成功后更新界面，避免看似成功而重启丢失。
- 错误分类至少包含网络/超时、认证/权限、限流、输出截断、输出结构不合法、证据不完整。学生看到可操作的中文提示，例如 **识别暂未完成，已完成的题目已保留** 和 **重试这道题**；本地开发记录保留精确阶段，隐藏密钥和非必要私密内容。

## 接口边界

接口统一位于 `/v1`，需本地配对令牌，使用 JSON 错误而非网页跳转。

| 接口 | 作用 |
| --- | --- |
| `GET /v1/health` | 返回服务版本和真实识别是否配置，不返回密钥，不等同于模型调用成功 |
| `POST /v1/recognitions` | 单张照片和幂等键，持久化后返回任务 ID；客户端组织最多十张 |
| `GET /v1/recognitions/:id` | 返回照片状态、逐题状态、候选和可操作问题 |
| `POST /v1/recognitions/:id/retry` | 重试指定的失败清单阶段或题目，不重跑成功内容 |
| `POST /v1/recognitions/:id/questions/:questionId/confirm` | 对当前版本提交用户校对与选择；过期版本拒绝 |
| `GET /v1/recognitions/:id/media/:mediaId` | 返回该任务真实原图或证据裁图，不接受客户端文件路径 |

响应包含契约版本、任务/题目稳定 ID、修订号、阶段、来源、自动检查与人工确认状态。原始模型响应保留在服务端受限目录，不全量发送到学生主界面。

识别任务不写入现有网页正式错题库。iPhone 的复盘与 PDF 使用真实候选经确认后的本地快照，保证旧练习包不会随重试改变。

## iPhone 数据改动

- 将当前只支持 `SampleProblem.all` 的列表、反思、选题和 PDF 改为统一题目模型，明确区分 example 与 recognized。
- 保存任务 ID、照片对应关系、来源证据、确认版本、题目快照。关闭应用后能恢复，网络不可用时仍能阅读已保存题和反思。
- 对现有本地状态做向后兼容迁移；损坏或未知版本仍保留并阻止危险写入，不重建空库。
- 中文界面不改写学生历史自由文本。旧版已保存的英文选项通过兼容映射显示中文，不能因翻译而失去选中状态、导致反思无效或丢失历史记录。
- 导入的原始字节继续保留，上传使用有记录的、方向正确的 JPEG 副本。超过上传限制时明确提示，不能悄悄低清压缩直到手写不可辨。
- PDF 使用题目快照并处理长题分页、全部小问和必要图示；不能沿用当前预置短题的一页高度假设而截断真实题。

## 模型选择

使用当前配置的 `qwen3.8-27b` 作为接入候选起点，并保留分阶段模型配置。先完成真实图片连通性检查，再运行十图；这里不声称它是效果最好的模型。

此前的多模型调查独立保留，其未完成部分不冒充最终结论。本轮不重启“所有模型”大规模测试，不创建新付费服务或更换账号。

北京地域兼容接口按百炼官方文档确认：`https://dashscope.aliyuncs.com/compatible-mode/v1`。模型和密钥在该接口当前是否可调用，以本轮实际返回为准。

## 本轮验收

### 自动化与安全

- 新功能先写失败测试，再实现。真实磁盘、路由、恢复和状态迁移需要测试；仅外部模型响应使用固定测试输入，不能把替身运行计为真实识别成功。
- 覆盖未授权访问、路径越界、过大/损坏图片、幂等冲突、部分成功、指定重试、服务中断恢复、过期确认、保存失败和凭据不泄露。
- Swift 覆盖旧状态迁移、真实题进入复盘、不自动选择、未确认题禁打印、练习包快照、离线读取；保留原有例题流程测试。
- 模拟器检查中文页面、原图、上传同意、识别进度、失败恢复、结果保存、复盘与 PDF。覆盖中文长提示、大字体布局和旧英文选项记录的兼容显示；除原始材料、专有名词及系统自有界面外，不残留英文主交互文案。记录实际设备/iOS 版本和截图，不能只报告编译成功。
