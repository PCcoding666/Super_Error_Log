# 手机网页视觉基础与前后预览：第一批

## 授权与目标

用户已确认六个 PR 的分批方式，并要求开始第一批：PR1 公共视觉基础与独立的前后预览。视觉方向已在对话确认：参考提醒事项的任务层级和备忘录的内容阅读体验，浅中性背景、单一青绿色强调色、清楚的文字层级，材质用于导航和操作层。

这一批让当前服务端页面具有一致的视觉基础，并让用户通过浏览器比较改前、改后。之后的首页重排、局部识别刷新、半屏操作、追问重排分别属于 PR2–6。本批不提前重写这些行为。

## 现有系统与边界

- 当前来源提交：`4317be8`，而不是旧的 `main`；实际生产入口仍是手机网页 `/s/`。
- TypeScript ESM、Express 5、React 19 SSR，无 hydration；发布包仅含 `dist/`。
- 公共样式当前在 `src/web/assets.ts`，页面外壳在 `src/web/views/layout.tsx`。
- 现有学习状态、表单动作、无脚本流程、邀请码和上传兼容性继续由当前实现提供。
- AI 仅提取和建议；学生自行提交反思；当天做对不算掌握；不增加逐题确认门槛。
- 使用合成题目、照片和固定的学习状态制作预览，不访问真实学生记录或生产服务。

## 视觉约定

1. 浅色底为接近系统分组背景的冷中性灰，内容面为白色；深色底和内容面使用不同明度的中性色。
2. 青绿作为主要操作、选中和焦点的强调色；错误、警告、成功各保留文字说明和语义色。
3. 正文默认 17 CSS px，以 rem 实现；标题提高层级，说明文字保持可读。统一 4/8 px 间距基数，内容横向留白约 20 px。
4. 页面卡片通过分组、留白和轻边界建立层级；不对题目或长文应用玻璃材质。
5. 主操作采用清楚的实色按钮，次要操作降低视觉重量；所有触摸目标至少 44×44 CSS px，主按钮约 52 px 高。
6. 底部操作层保留安全区、动态高度和内容留底空间；支持浏览器文本放大、窄屏、深色、减少动态与减少透明效果。
7. 按压和选择反馈简短，减少动态时移除非必要动画；焦点轮廓可见。
8. 练习纸的 A4 排版和打印专用 CSS 保持现有结果。统一屏幕样式时不把 UI 材质带入纸面。

## 预览交付

旧版从冻结提交单独检出。生成器分别加载旧版和当前工作目录的真实 SSR 组件及其资源；两侧使用同一套合成页面输入。禁止用一份新版 DOM 加旧 CSS 冒充旧版。

预览至少涵盖：邀请码登录、今天、上传说明、拍照、照片识别状态、题目列表、选题、追问、设置。可再包括打印和结果。两侧页面与状态一一对应；题目素材、日期和文本一致。

托管交付是独立的静态合成数据交互演示，明确说明真实页面导出、演示行为在浏览器发生，不能用于验证真实 AI、相机、录音或服务器保存。交互适配只存在于预览目录，不进入生产页面。支持真实原生输入、选题数量反馈、演示状态跳转和设置反馈；页面内清楚标注可用范围，不能让按钮无声失效。

对照入口提供页面选择、旧版/新版打开入口和同尺寸并排画面；手机上可切换版本或分别打开。保存 PNG 对照和短录屏，并记录来源提交、固定数据日期和浏览器尺寸。

预览通过 Sites 的独立 owner-private 站点交付，保持本项目生产站点与真实记录独立。站点源只包含生成的合成页面、素材和对照报告，不上传私有应用源码、凭证、会话或真实记录。

## 验证与验收

- 先运行当前基线的 `SEL_AI_MODE=mock npm run verify`，记录本环境结果。
- UI 修改完成后运行同一完整检查；有环境限制时明确记录。
- 浏览器检查 390×844 浅色/深色、窄屏、200% 文本、键盘焦点、减少动态，以及底栏和最后内容可滚动访问。
- 对实际 CSS 值计算正文、次要文字和语义色对比度；正常文字达到 4.5:1，主要输入边界/焦点满足 3:1。
- 对照生成器校验来源、实际页面路径、资源完整性与隔离；预览不存在生产请求、有效邀请码和会话。
- 全量 E2E 仍承担上传、周末 A/B、语音替身、无 JS 和纸张 PDF 的行为验证；视觉截图不替代这些检查。
- 最终交付第一批代码、可访问的对照站点、截图/录屏以及验证说明；不自动部署现有学生应用。
