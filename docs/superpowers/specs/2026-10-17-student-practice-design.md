# Student practice flow

Approved in chat on 2026-10-17: three entries (错题录入 / 错题本 / 练习), library by default, no calendar-driven instructions. Preserve existing subject/grade/chapter browsing and upload compatibility.

Create a practice from selected questions. Default to reading on a phone and writing on paper. Answers start hidden; hints are optional. Save each result immediately and resume unfinished questions. Skipping leaves the question unfinished. Result recording must not require a photo or a print action.

After finishing, offer photo upload or direct self-check. Store photos and extracted handwriting against the exact practice and question, never as a new error item. No automatic grading. Failed recognition must retain the photo and permit self-check; retrying must not duplicate attachments or overwrite a newer upload.

A prominent print option uses the same frozen question content. Printable questions have writing space; answers are an optional separate final section. Printing never completes or resets a practice. Paper results return to the same practice and save per question. Keep existing mastery rules, evidence safeguards, student isolation and authentication.

Delivery: four reviewable PRs (navigation; online practice; optional handwriting; printing). User authorized implementation and submission without another approval round. No merge/deploy requested.
