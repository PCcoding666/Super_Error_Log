## 1. 产品命题（不变）与学生眼里的产品

> 为工作日不能用电子设备的初三住校生，把一周纸质错题在周末十几分钟内变成一份可带回学校的个性化练习，并用隔几天的独立作答（而不是抄答案、看答案）来证明掌握。

学生眼里只有五种题的状态：**错题 / 不是错题（删）/ 本周练习中 / 暂时掌握 / 再做一次**。AI 的把握程度是徽标，不是状态；识别、检查、分类都是后台的事。

学生每周只有两次接触：周六晚 12 分钟以内（拍、扫一眼、复盘 5–8 题、打印），下周六 5 分钟以内（回传、看回报）。

## 2. 终端与数据归属

```
iPhone（主操作端）   ──HTTPS/设备令牌──▶   服务器（系统记录源）   ◀──只读──   Web 看板（家长聚合 / 审阅）
  拍照·扫一眼·复盘·打印·回传             识别·出题·排期·掌握判定·统计
```

**架构决定（2026-09-29 核实后）**：Web 版已经实现了错题状态机（11 态）、可解释选题、练习包与 A4 PDF、回传与掌握事件、诊断追问（`clarificationQuestion`）和分级提示（`coach`），只是从未部署，手机也没连它。线上只跑着识别服务（`dist/mobile/server.js`，文件式任务存储）。因此 v2.0 **不重写学习记录**，而是：

- 一个服务器进程同时挂载：现有识别服务（`/v1/recognitions`，不变）+ 新的手机 JSON 接口（`/v2/...`，背后调用现有 `services/`）+ Web 页面（退为只读看板）。三者共用一个 SQLite 数据库。
- 新增一座"桥"：识别任务里学生"留下"的题 → 生成 `error_item` + `evidence_record`（含裁图、区域、观察、知识点、把握徽标）。桥是唯一新写的持久化逻辑。
- 手机端删除本地学习状态（反思、练习包、结果），改为读写 `/v2`；只保留照片与离线缓存。

- 服务器新增的记录（概要，§11 详列）：错题 Question、文档组 DocumentSet、反思 Reflection、练习集 PracticeSet 与练习项 PracticeItem、作答 Attempt、掌握状态 Mastery、修正历史 Correction、知识点表 KnowledgeTag。
- 手机保留：原始照片、离线可读的缓存副本、未提交的草稿。手机不再是任何学习记录的唯一存储。
- 现有 Web 的评分、状态机、排期、PDF 版式作为服务端能力复用，页面退为看板。

## 3. 学生的一周（屏幕级）

### 周六晚（≤ 12 分钟）

**S1 拍。** 首页只有一个主入口"拍这周的错题"。取景框内一句提示："整页拍全，别裁边；题目和你的作答都拍进去"。连拍多页。上传同意只在第一次安装时问一次，之后不再弹。拍完自动上传，可以放下手机。

**S2 后台。** 系统：切题 → 只把有批改标记或有订正痕迹的题当"错题候选"，其余题目保留在库里但不出现 → 转写题干、读出学生原作/订正/批注 → 学科/知识点分类 → 自检。自检不通过只打徽标，**不拦、不弹窗**。

**S3 扫一眼。** 一屏是这周的错题卡（约 20 张）：裁图缩略、题号、学科、知识点、AI 把握徽标。每张卡两个动作：**留**（默认）/ **不是错题**。角落入口："不对，改一下"（§8）。30 秒到 1 分钟。

**S4 本周练习。** 系统从留下的题里选 5–8 道进本周练习，每题一句理由（把握低 / 概念错 / 同类错误上周也出现过），并说明练习形式（原题重做 / 换个数字 / 同知识点新题）。学生可以换题、去掉，上限 8。

**S5 复盘，只对这 5–8 道。** 每题一屏：裁图 + AI 读出的"你当时写了…，订正是…" + 一句追问。学生**按住说话**（或打字）答一句。AI 给出错因类别和一句归纳，学生确认或改。再选把握四档。每题 30–40 秒（§7）。

**S6 打印。** 预览这份练习包（这是唯一需要他看一眼内容对不对的时刻，有错点"改"）。生成 PDF，系统分享/打印。封面写做题日和三条规则（§6）。

### 周中：在学校做纸。

### 下周六（≤ 5 分钟）

**S7 回传。** 逐题：怎么做的（独立 / 看了提示 / 没做出来）、对不对、哪天做的。可拍做完的纸作为记录。屏幕左边这次作答（拍的），右边原图红笔订正，自己判对错。

**S8 回报屏。** "6 道里 4 道独立做对 → 暂时掌握，两周后再确认一次；2 道下周再来。你说'有把握'的 5 道里，1 道没做出来。" 然后直接进入本周 S1。

被删除的交互：逐题确认页、"我已逐项对照"开关、人工放行弹窗、分批同意、示例题、三个 Tab、"由你选择不是待办"、手动刷新按钮。

## 4. 识别"默认成立"的前提：分项准确度测量与兜底策略

### 4.1 为什么要分项

现有数据都是**模型自检**的结果（verify 阶段），不是人工真值：2026-09-19 两张真实照片 57 次 verify 调用，剔除照片物理裁边的题后，qwen3.8-max 的自检失败率为 题干完整 0%、裁图完整 50%、裁图纯净 33%、转写一致 0%、图示安全 0%；2026-09-15 十张照片 43 道候选 40 道待核对，人工抽查发现 √16→√13、3/2→3、+6x→+6y 三处**笔迹转写**错误。这些数字说明：不同字段的可靠性差距很大，"一半题没把握"主要来自裁图坐标，而不是题干文字。所以兜底必须按字段定，不能一刀切。

### 4.2 测量方案：修正即测量（D14，取代人工逐题核对）

- 不做几十道题的人工标注。让学生真实用一周，识别结果的每一处都有"不对，改一下"入口（§8）。
- 每次修改落一条 `Correction` 记录：题目、字段（下表八项之一）、改前、改后、方式（语音指令 / 键盘 / 重识别）、时间。
- 每周产出一张"按字段的修改率"表：修改次数 ÷ 该字段出现次数。修改率就是错误率的下界；连续两周后按 §4.3 调整兜底。
- 手头的 12 张真实照片（`data/mobile-pilot-20260914-krC7gn`、`data/real-pilot-20260907`）只用于开发期自测，不做正式标注。
- 需要统计的字段：

| 字段 | 真值判定 | 错了会影响什么 |
|---|---|---|
| 错题识别（有批改/订正 → 候选） | 漏报 / 误报 | S3 列表多题或少题 |
| 题目定位与裁图完整 | 裁图含完整题干、不混邻题 | 打印裁图、缩略图 |
| 题干转写 | 逐字对照，公式/单位/图形引用 | 打印文字、变式出题 |
| 学生原作转写 | 数字、符号、涂改 | 追问、错因归纳 |
| 订正/批注转写 | 同上 | 回传对照、答案 |
| 图示裁取 | 完整且不含作答 | 打印 |
| 学科/知识点 | 与教材章节对应 | 推荐、归类、题库匹配 |
| 参考答案提取 | 有无、是否正确 | 答案页 |

- 输出：一张按字段的错误率表 + 每类错误 3 个典型样例，写入 `docs/quality/`。

### 4.3 预设的兜底策略（测量后按数字调整）

| 字段错误率 | 策略 |
|---|---|
| 题干转写低错 | 直接用文字打印 |
| 裁图不稳（当前最差） | 打印时凡自检"裁图不完整/不纯"的题，**改印遮白裁图**（作答/订正/批注区域遮白），文字只作展示 |
| 笔迹转写有错 | 追问时把裁图和转写并排给学生，追问语言用"你写的是…吗"而不是断言 |
| 错题识别漏报 | S3 底部折叠"同页其他 N 题"，一键补入 |
| 知识点不准 | 学生在 S5 可改，改动只影响标签，不作废证据 |
| 参考答案缺失 | 答案页写"对照原卷"，不硬造 |

原则：**任何字段的错误都不能变成学生的常规劳动**，只能变成系统的兜底或学生的例外修正。

## 5. 本周练习的构成（D8）

每道进入本周练习的错题，对应**一道练习项**，来源按错因和可得性决定：

| 来源 | 适用 | 生成方式 | 质量门 |
|---|---|---|---|
| A 原题重做 | 概念 / 方法 / 推理类错因；或其他来源不可用时的兜底 | 直接用 | 无模型风险 |
| B 变式 | 计算 / 审题 / 表达类错因（原题三天后会靠记忆做对） | 同结构换数字/条件，保留考点 | 见下 |
| C 从错因出发的新题 | 追问归纳出明确误区（如"漏看取值范围"） | AI 出一道同一陷阱的新题 | 见下 |
| D 题库匹配 | 同知识点、同错因 | D0：他自己材料里同页同知识点、他做对或没做的题（清单已列出，真实且老师选过）；D1：外部题库（学科网等，需授权与接口，本阶段不做） | D0 无风险 |

出题质量门（B、C 必须全部通过，否则退回 A）：
1. 产物必须包含：题干、标准答案、简解、一级提示（考什么）、二级提示（第一步）。
2. 独立复核：另一次调用（不同提示词）盲解该题，答案与标准答案一致才通过。
3. 形式检查：数值合理、单位齐全、不引用不存在的图；需要图示的题目本阶段不生成（退回 A）。
4. 纸上标注来源："换个数字再做" / "AI 出的同类题"，学生回传时可点"这题有问题"，反馈进入出题黑名单。

掌握判定口径：**对应错题的掌握，以该练习项的延迟独立正确为证据**，不区分原题或变式；变式做对的证据强度记为更高（迁移），在趋势页体现。

费用封顶：每份练习包最多 8 次出题 + 8 次复核；失败不重试，退回 A。

## 6. 复习方式与纸质练习包规范 v2（D6）

复习方式的核心不是"再看一遍"，而是**隐藏答案的独立作答 + 卡住时的最小提示 + 做完能自己判 + 下周看两次作答的差异**。全部发生在纸上，不需要屏幕。

练习包结构（A4，黑白）：
- **封面**：周次、做题日（如"周三晚自习"）、三条规则（不看答案；卡住先看一级提示，再看二级；做完打勾写日期）、题目清单（短 ID + 来源标注）。
- **题目页**（每题不跨页，允许一页两题）：短 ID、学科·知识点、题干（文字或遮白裁图）、必要图示、一行"这题的关键一步是：______"、演算区、勾选框（□ 独立做出 □ 看了一级提示 □ 看了二级提示 □ 没做出来 ｜ 做题日期 ____）。
- **末页可撕**：按短 ID 索引的一级提示、二级提示、答案（有参考答案的印答案，没有的印"对照原卷第 x 题"）。
- 题目页禁止出现：答案、他的原作、订正、批注。
- 程序检查：A4、页数、题目页无答案文本、每题短 ID、末页存在。

## 7. 错因追问（D7）

目标：像一个懂题的老师追问一句，让学生自己说出来哪里想错了；不讲解，不替他写。

流程（每题一次，最多两轮）：
1. AI 读证据（题干、原作、订正、批注）后提出**一个**具体问题，必须引用他写的东西："你原来写 √16，订正是 √13，你当时是怎么得到 16 的？"证据不足时问开放句："这题你当时卡在哪一步？"
2. 学生按住说话（端上识别成文字，可改）或打字，一句话即可。
3. AI 给出：错因类别（七类之一）+ 一句归纳（"把 3²+4² 当成了 3+4 再平方"）+ 是否建议变式。学生点"对"或改类别。
4. 学生选把握四档（永远不建议、不预选）。

硬边界：不输出解题过程；不评价对错以外的事；一题最多两轮；只对进本周练习的题做；全部记录为 Reflection（含他的原话）。学生的原话在纸上不印（避免变成提示）。

## 8. 修正识别结果（D9、D10）

- 入口：错题卡角落、复盘页、打印预览页都有"不对，改一下"。
- 交互：按下即录音（端上识别，音频不出设备），松开后显示文字稿可编辑，点"生成修改"。服务器用文字稿 + 当前证据生成修订包（前/后对照），学生"接受"才生效；有歧义时 AI 反问一句。
- 规则：只修正**转写保真**（识别错的字、漏的条件），不允许把学生原作的数学内容改对；修正后该题的自检失效并重跑，revision 递增；修正历史可撤销。
- 接口沿用 2026-09-27 设计稿 M2 草案（revision 乐观锁 + clientRequestId 幂等）。

## 9. 答题卡 / 答案与题目分离（D11）

真实材料有四种组合：题目与作答同页（现在唯一支持的）；试卷 + 答题卡；练习册题目 + 作业本作答；题目 + 单独的答案页/答案册。

### 9.1 工程方案：文档组 + 题号关联

- 新增 **DocumentSet**（一次作业/一份考试）：同一次拍摄会话内的照片默认归入一组；学生可拆分/合并。
- 每张照片先判**页面类型**：试卷页 / 答题卡 / 作业本 / 答案页 / 混合。答题卡与作业本页的清单只产出"题号 + 作答/批改"，不产出题干；答案页只产出"题号 + 参考答案"。
- 组内按 **题号 + 学科 + 相对顺序** 关联：题干来自试卷页，作答/批改来自答题卡或作业本，参考答案来自答案页。关联置信度低的题打徽标。
- 找不到题干的作答（只拍了作业本）：错题卡显示"第 5 题：找到你的作答，没找到题目"，主操作"拍一下题目页"。找不到作答的题干（只拍了试卷）：不进错题候选。

### 9.2 交互

- S1 拍完后，若检测到答题卡/作业本页，提示一句："这份还有题目页吗？现在拍，或稍后补。"
- S3 错题卡上显示关联状态：完整 / 缺题目 / 缺作答 / 关联不确定（点开可手动指定题号）。
- 不做的事：不要求学生给照片命名、排序、手动分组。

### 9.3 测量

§4.2 样本中必须包含答题卡和作业本各至少 1 张，单独统计"页面类型判定"和"题号关联"的错误率。

### 9.4 2026-10-02 修订：先找题、学生勾、再精读（取代 9.1–9.3 作为第一步）

真实使用前复盘时确认：只靠批改痕迹判断错题，在"答题卡 + 网上阅卷"的学校行不通；而 9.1 的自动配对成本高、容易错。改为分三步做，每一步都能独立上线。

**第一步（v2.1a）：勾选**

- 找题（清单）阶段不变：找出页面上全部题目的题号、位置、有没有批改痕迹。
- 有痕迹的题（`marked_wrong` / `corrected`）自动进入精读，和现在一样，学生不用做任何事。
- 没有痕迹或看不清的题（`unmarked` / `unclear`）标为"未选"：不精读、不计费、不算识别进度。
- 学生在这张照片的勾选面板里点选，或说/输入题号；确认后这些题才精读并进入错题本。学生勾进来的题和自动预勾的题之后一视同仁。
- 学生也可以表示"这页没有别的错题"，这一提示就收起。
- 预勾错了的题仍用"不是错题"移出（已有）。
- 测量：周报里记"学生手动勾入的题数"，它与"不是错题"的数量一起反映批改痕迹判断的准确度。

各种学校做法的覆盖：

| 学校的做法 | 学生的操作 |
|---|---|
| 老师直接在试卷上批改 | 无，自动预勾 |
| 讲评时自己在卷子上打叉、订正 | 无，自动预勾 |
| 试卷 + 答题卡都发回来 | 拍试卷页，点选或报题号 |
| 网上阅卷，只有成绩单 | 拍试卷页，报题号（第二步起可导入成绩单截图） |

**第二步（v2.1b）：成绩单截图。** 学生从相册导入阅卷系统的小题分截图，AI 读出"题号 / 满分 / 得分"，丢分的题号自动在勾选面板里勾上，学生确认。只读表格，不读题目内容。

**第三步（v2.1c）：补上自己的作答。** 勾进来的题如果页面上没有学生作答：选择题点一下当时选的选项；解答题可补拍答题卡上自己写的那一块，AI 转写成"你的作答"。没有作答的题，追问退回开放句（已有行为）。

不变的原则：AI 只找题、转写、提问，不判断学生答得对不对；哪道是错题由批改痕迹或学生本人决定。

## 10. 回传、回报与掌握判定

- 回传字段：完成方式（独立 / 一级提示 / 二级提示 / 没做出来）、对错、做题日期、可选"卡在第几步"、可选做完的纸的照片。
- 判定（沿用 v1 规则）：做题日期 − 打印日期 ≥ 3 天且独立做对 → 暂时掌握；提示 / 做错 / 没做 → 再做一次（下周优先入包）；暂时掌握 7–14 天后再次独立做对 → 稳定掌握；同日做对不产生掌握事件。
- 回报屏必须回答三件事：这周几道真会了；哪几道下周再来；他的把握和结果差在哪。
- 复习时机（D5 挂起）本阶段只做：练习包封面印做题日；回报屏给出下一轮日期。

## 11. 服务器记录与接口（概要，供拆任务）

记录：`DocumentSet`、`Photo`（页面类型、组内序）、`Question`（题干、裁图、区域、观察、知识点、把握徽标、revision）、`Correction`、`Reflection`（追问轮次、学生原话、类别、归纳、把握）、`PracticeSet`（周次、打印日期、做题日）、`PracticeItem`（来源 A/B/C/D、题干、答案、提示、短 ID、对应 Question）、`Attempt`（完成方式、对错、做题日期、照片）、`Mastery`（状态、事件历史）、`KnowledgeTag`（规范表）。

接口族：拍照上传（组内）、错题卡列表与留/删、修正（语音文字稿）、本周练习推荐与调整、追问/反思、练习包生成与 PDF、回传、回报与趋势、家长聚合（Web 只读）。现有 `/v1/recognitions` 保留为内部识别任务接口。
