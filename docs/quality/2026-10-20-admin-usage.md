# 管理后台：账号用量与调用性能

日期：2026-10-20。交付为开发分支及 PR，本功能尚未合并或部署，未初始化生产管理密码。

## 范围

用户确认关注输入/输出 tokens、调用耗时、成功率和失败原因。新增独立登录的 `/admin/`，提供邀请码编号与账号对应关系、累计使用统计、模型/功能汇总、失败分类及分页明细。筛选按账号、UTC+8 自然日、模型和调用阶段生效。

邀请码补发不重复累计账号用量。历史邀请码只有哈希，后台展示独立编号，不还原原码或展示哈希。后台只读聚合元数据，不展示学生题目、照片、录音、反思、提示词、模型响应或凭据。

## 数据口径

- 每次实际 HTTP 尝试分别记录，重试分别计数；供应商已返回的失败调用 usage 仍保留。文本/视觉与原生语音调用进入每学生独立的统计库。
- 未知 tokens 和耗时显示“未采集”，已报告总量只代表可计量部分。均值与 P95 只用有耗时的样本，P95 取最近秩。
- 耗时覆盖请求至响应读取/解析，不含排队和业务处理。接口成功不代表识别正确、业务校验通过或学生掌握。
- 历史视觉日志只恢复现存字段，并按调用 ID 去重；旧文本/语音和未落盘调用不能完整追溯。
- 调用分类沿用现有模型阶段：`transcribe` 包含图文/手写转写和纸上练习作答核对。没有新增模型请求或收费探测。
- 累计使用统计不随 AI 日期筛选改变；题目照片不包含练习作答或反思附件，“已生成打印包”不是实际打印次数。活跃时间写入遇到锁或存储异常会跳过，不影响学生访问。

## 安全与集成

管理凭据和会话独立于学生注册表；scrypt 派生密码、会话哈希、12 小时会话、独立作用域 cookie、同源 POST、防缓存和登录限速。服务器 CLI 生成/轮换密码后旧管理会话立即失效，学生会话不变。账号的 `admin` 身份标签不会授予后台权限。

功能已对齐 `origin/main=d8caee1`，保留当前角色迁移、语音会话绑定及纸上练习功能。主进程挂后台，学生 worker 和旧单学生部署不挂后台。只增加兼容的注册表列及独立文件，无新增运行时依赖。

初次登录和回滚说明见 [部署文档](../../deploy/README.md#管理后台账号用量与-ai-性能2026-10-20-开发版本尚未部署)。
