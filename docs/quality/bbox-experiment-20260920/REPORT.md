# 坐标约定对照实验 — bbox 格式与思考模式对定位精度的影响

日期：2026-09-20 01:08–01:15 · 执行：WorkBuddy（用户指示 run now）
对象：真实照片 job `e2121b77`（用户 iPhone 上传，源图 3024×4032），定位目标 = 第 2 题完整题干行
模型：qwen3.8-max（同一模型、同一原图、同一任务，仅变坐标约定）

## 背景

生产管线 transcribe/ground 阶段的 questionRegion 失败率（cropComplete=false）在 qwen3.8-max 下仍为 50%。对照 Qwen-MM-Plugins 官方 grounding 实现发现三处约定差异：坐标格式（官方 0–1000 对角点 vs 我们 0–1 xywh）、思考模式（官方关闭 vs 我们默认开）、双格式解析兜底。

## 实验设计

| 条件 | 坐标格式 | 思考模式 | 提示词风格 |
|---|---|---|---|
| A 官方配方 | 0–1000 `[x1,y1,x2,y2]` | 关闭 | 官方 grounding 模板（照抄 grounding.py:129-134） |
| B 我们配方 | 0–1 `{x,y,width,height}` | 默认 | 生产管线 SAFETY+BOX 提示词 |
| C 隔离变量 | 0–1 xywh（提示词） | 关闭 | 无 system 的裸任务 |

每条件 3 次独立调用，结果统一换算为 0–1 对角点与像素坐标，并用 sharp 按预测框实裁保存（本目录 exp-*.jpg）。

## 发现

### 1. 思考模式是关键变量，格式是次要变量

- **条件 A（思考关 + 0–1000）**：三次输出高度一致（x1 均 0.19±0.002，y2 均 0.182–0.183）。y1 稳定在 0.140–0.148——**不再向上越界**到第 1 题区域。
- **条件 B（思考开 + 0–1，即生产配方）**：run1 的 x1 飘到 0.110（比 A 偏左 0.08，约 247px），run3 y 偏移 0.009——**同格式下开着思考时输出漂移明显更大**。
- **条件 C（思考关 + 提示 0–1）**：模型**无视提示词的 0–1 约定，直接输出 0–1000 整数**（x=192 与 A 的 192 一致）——证明 0–1000 是模型在无思考时的原生坐标词汇；解析侧若不做兜底会当成 0–1 而崩溃。

### 2. 精度提升的直接证据

与生产管线实际输出（裁图截断、混入邻题）对照：

- A 三次的 y2（0.182–0.183）都**覆盖了题干完整高度**，实裁图（exp-A-1/2/3.jpg）题干末尾「则 a 的值为______.」完整可见，未截断；
- A 的 x1（0.190–0.192）与候选框 x=0.235 相比向左扩展至题号起点，正确包含「2. (2025 长沙)」的题号与来源标注；
- 唯一残留差异：A 的 x2（0.806–0.853）比候选框右缘（0.915）保守，三次中 run3（0.853）最接近题干实际结束位置——即横向右缘仍有 ±0.04 的估计方差，但**不再产生「混入邻题」或「截断题干」的致命错误**。

### 3. 生产管线可直接采纳的三个改动

1. **transcribe/ground 的坐标请求改为 0–1000 对角点整数**，并带双格式解析兜底（先 JSON，后 `<ref><box>` 标签；同时容忍模型把 0–1000 写进 0–1 字段——用数值范围 >1 自动判别制式）；
2. **enable_thinking=false 用于所有定位类调用**（transcribe/ground 的坐标部分；verify 的布尔判定可保留思考）；
3. 坐标后处理仍保留：与候选框求交/加权融合、越界钳制（应对横向 ±0.04 残差）。

## 局限

- 单题（第 2 题）×9 次调用，样本小；第 2 题是单行填空题，多行大题的纵向高度回归未测；
- 未测 inventory 阶段（整页多候选定位），该阶段已有候选框锚点，受益可能较小；
- B 的 run1（x1=0.11）单次漂移也可能是采样噪声，但与 A 的零漂移形成对照，方向性结论可信。

## 归因修正（2026-09-20 01:20，立计划前核对生产代码后）

实验后核对 `src/ai/chatClient.ts:99/110` 发现：**生产管线对全部百炼/qwen 调用已经发送 `enable_thinking: false`**。因此本实验的条件 B（思考开）并不等于生产配置；生产管线与官方配方的实际差异只剩**坐标格式**（0–1 小数 xywh vs 0–1000 整数对角点）。条件 C 证明关思考时模型无视 0–1 指令、直接输出 0–1000（与 A 数值一致），即 0–1000 对角点是 qwen3.8-max 无思考模式下的原生坐标词汇——**坐标格式是主变量的结论不变且更强**：生产管线用 0–1 xywh 时模型需要「现场换算进制」，这正是坐标漂移与截断的来源。条件 B 的思考开差异仅用于解释实验内部行为，不构成生产归因。

## 结论

**qwen3.8-max 的坐标回归能力在 0–1000 对角点整数格式下显著优于 0–1 小数 xywh**：输出稳定（x1 三次 0.19±0.002）、不再越界、不再截断题干。生产管线 cropComplete 失败的主因是坐标格式偏离模型原生词汇表，而非模型能力不足。修复方案以坐标格式切换 + 制式判别兜底 + 坐标后处理为主；思考模式在生产已是关闭状态，无需改动（verify 阶段同）。
