# 年级 / 学科 / 章节分类与跨章节选题

## 本轮范围

用户已确认：一级为年级（初一、初二、初三），二级为学科，三级为章节或知识主题。学生设置的年级作为新题默认值，当前默认初三。仅修改单题归属，不做分类统一改名或合并。支持同时选择多个章节的全部错题。

- 错题本按年级、学科浏览，章节显示题数，可展开查看题目；勾选多个章节后进入原有选题页。
- 所选范围包括历史题目，不受当前展开状态、周次或推荐前 8 题限制。
- 仍执行已有的练习资格和每次最多 8 题规则。已在未回传练习中或未到复习时间的题显示排除数量；超过 8 道保留全部可选题，学生自行取消，不静默截断。
- 详情提供直接修改年级、学科、章节的表单。“未分类”允许保留，不强迫学生编造章节。学科和章节可手填（1–100 字）。
- 设置页新增年级选择，修改默认年级不迁移旧题。
- 卡片采用年级、学科、章节；细知识点保留在题目详情中，不作为章节筛选键。识别提示词明确 chapter 与 knowledgeTags 的区别。
- 现有自动推荐仍沿用原来的延迟重做、复发知识点和题数规则；本轮不改变掌握判定。

## 数据兼容

新增 `item_category` 表，用复合外键约束题目与学生归属。原始题干、识别证据、细知识点、学习状态和既有打印快照均不改写。

年级在桥接新题或首次读取旧题时保存；调整学生默认年级前为尚未读取的旧题补齐原默认年级。手动学科、章节作为独立覆盖值，优先于模型结果及上传学科。没有手动覆盖时优先使用上传时选定的学科；若与 AI 学科不同，不沿用另一学科的章节。

旧数据无需重新调用 AI。已知细知识点（例如根的判别式、求根公式）归入对应章节；无法确定章节的题保留“未分类”。该表为附加结构，旧版仍可读取原始题目表；没有破坏性迁移或生产数据清理。

## 验证

专项用例覆盖：单题编辑及非法输入；所有年级的新题默认值和旧题不漂移；不同学生归属校验；原证据不变；细知识点归章节；跨章节包含历史题；9 道选择不截断，调整到 8 道后建练习；有脚本和无脚本提交；学科 cookie 经邀请码网关传递并在退出时清除。

独立代码审查发现“未分类”输入被清空导致无法只改年级，已保留其显式值并添加回归测试。

最终 `SEL_AI_MODE=mock npm run verify` 通过：typecheck/build；Vitest 71 个文件、847 项通过 / 2 项既有跳过；Playwright 41 项通过 / 5 项既有可选证据用例跳过。已逐文件比较验证副本与本分支的 src/tests，内容一致。本地托管工作区处于 `.codex` 隐藏目录，旧 demo PDF 下载会触发交接文档已有的 Express dotfiles 限制，因此最终门禁使用非隐藏目录的同内容副本；生产下载权限未修改。
